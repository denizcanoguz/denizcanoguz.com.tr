# denizcanoguz.com.tr

Personal CV site of Deniz Can Oğuz, live at [denizcanoguz.com.tr](https://denizcanoguz.com.tr).

Built with [Astro](https://astro.build) on the [Starfolio](https://github.com/webrating/starfolio) theme (MIT).

## Editing

All content lives in `src/data/resume.tsx`. Push to `main` and GitHub Actions builds and deploys the site to GitHub Pages.

## Local preview

```bash
npm install
npm run dev
```
